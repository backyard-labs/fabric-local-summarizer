# Fabric Local Summarizer

An interactive Windows command-line utility for summarizing web pages, YouTube transcripts, local documents, and media using [Fabric](https://github.com/danielmiessler/fabric) and [Ollama](https://ollama.com/).

The project includes two implementations:

- **PowerShell:** `Fabric-Summarize.ps1`
- **Python:** `Fabric-Summarize.py`

Both provide an interactive workflow for selecting content, choosing a locally installed Ollama model, generating a summary, measuring execution time, and optionally saving the results as Markdown.

> **AI authorship disclosure:** Both scripts were generated by OpenAI's ChatGPT through a human-directed development and testing process. The project owner does not claim to have personally written the source code. See [AI-Assisted Development Disclosure](#ai-assisted-development-disclosure).

## Features

- **Five input categories:** Web pages, YouTube transcripts, local text files, PDF/Word documents, and audio/video files.
- **Automatic Ollama model discovery:** Retrieves installed models using `ollama list` each time the script runs.
- **Interactive model selection:** Choose from available local models without editing configuration files.
- **Windows file picker:** Browse for local files rather than manually entering paths.
- **Execution timing:** Displays the time spent processing the Fabric command.
- **Markdown export:** Optionally save generated summaries to a Markdown file.
- **Long-input warning:** Warns when local text input exceeds 8,000 characters and requires confirmation before continuing.
- **Two implementations:** Use either PowerShell or Python according to your preference.

## Requirements

### Core Dependencies

| Component | Purpose |
|---|---|
| Windows | Target operating system |
| PowerShell or Python 3 | Runs the corresponding script |
| [Fabric](https://github.com/danielmiessler/fabric) | Summarization workflow and prompt patterns |
| [Ollama](https://ollama.com/) | Local language-model inference |
| At least one Ollama model | Generates summaries |

Fabric must be configured to use Ollama, and the relevant command-line tools must be accessible through the system's `PATH`.

### Additional Dependencies by Input Type

| Input | Requirements |
|---|---|
| Web page URL | Network access and Fabric's configured web retrieval integration |
| YouTube video URL | `yt-dlp` and network access |
| Plain text and transcripts | No additional tools |
| PDF document | Poppler's `pdftotext` |
| Word `.docx` document | Pandoc |
| Local audio/video | Fabric transcription configuration; `ffmpeg` may be required for larger files |

Supported plain-text inputs include `.txt`, `.md`, `.vtt`, `.srt`, `.log`, and `.csv`.

**Important:** The audio/video transcription feature is separate from Ollama summarization. Depending on the Fabric configuration, transcription may use an external service and incur charges.

## Getting Started

### 1. Install and Configure Fabric and Ollama

Follow the official installation instructions:

- [Fabric](https://github.com/danielmiessler/fabric)
- [Ollama](https://ollama.com/)

Ensure Fabric is configured to use your local Ollama service.

Download at least one model, for example:

```powershell
ollama pull llama3.2
```

Verify that Ollama can list the installed models:

```powershell
ollama list
```

Also verify that Fabric is accessible:

```powershell
fabric --version
```

### 2. Clone the Repository

```powershell
git clone https://github.com/backyard-labs/fabric-local-summarizer.git
cd fabric-local-summarizer
```

### 3. Run the PowerShell Version

```powershell
.\Fabric-Summarize.ps1
```

If Windows blocks the script because it was downloaded from the Internet, review the script and consult the [PowerShell Known-Good Scripts Runbook](docs/PowerShell-Known-Good-Scripts-Runbook.md).

Do not routinely disable PowerShell security controls to run downloaded scripts.

### 4. Run the Python Version

```powershell
python .\Fabric-Summarize.py
```

Python 3 must be installed and available in your terminal.

## How It Works

When launched, the utility presents five source options:

```text
Fabric Summarizer

Choose the content you want to summarize:
  [1] Web page URL
  [2] YouTube video URL
  [3] Local text, transcript, or notes
  [4] PDF or Word .docx document
  [5] Local audio or video file
```

After choosing a source:

1. Enter a URL or select a local file.
2. The script prepares the content for Fabric.
3. For applicable local text inputs, the script checks whether the content exceeds the long-input warning threshold.
4. The script executes `ollama list` and presents the installed models.
5. Select the model you want to use.
6. Fabric runs its `summarize` pattern using the selected Ollama model.
7. The generated summary and Fabric execution time are displayed.
8. Optionally save the result as a Markdown file.

### Dynamic Model Discovery

The model list is **not hardcoded**.

Both implementations query Ollama at runtime:

```powershell
ollama list
```

Newly installed models automatically appear in the selection menu on subsequent runs. Removed models no longer appear.

### Long-Input Protection

For supported local text inputs, the scripts display a warning when the extracted text exceeds 8,000 characters.

The warning includes an approximate token count based on character length and asks whether to continue. The default response is cancellation.

This is a precaution against unexpectedly large inputs, not a tokenization engine or automatic document-chunking system.

The actual context limit depends on the selected model, its configuration, Fabric's instructions, and the input content.

### Execution Timing

The reported duration measures the Fabric processing call.

It does not represent the entire interactive session, including source selection, file browsing, or other preparation steps.

## Privacy and Security Considerations

**Local Ollama inference does not mean every operation in this workflow is offline or private.**

### Local Processing

- Ollama performs summarization inference locally when configured to use the local service.
- Local text and extracted document content are passed to Fabric for processing.
- Summary files are saved locally when the user chooses to export them.

### Network and External Services

- Web page retrieval uses Fabric's configured web retrieval integration, which may involve Jina.
- YouTube transcript retrieval requires network access.
- Audio/video transcription may use an external provider, depending on Fabric's configuration.
- External transcription services may process uploaded content and may incur usage charges.

Users should inspect their Fabric configuration and understand the data flow before processing confidential or sensitive material.

### Script Execution

The scripts invoke external command-line utilities installed on the user's system.

Users should:

- Review the scripts before execution.
- Install dependencies from trusted sources.
- Avoid running the scripts with unnecessary administrative privileges.
- Verify the behavior of external utilities and their configurations.
- Exercise caution when processing untrusted documents, media, or web content.

For PowerShell-specific guidance, see:

[PowerShell Known-Good Scripts Runbook](docs/PowerShell-Known-Good-Scripts-Runbook.md)

Removing a downloaded file's Mark-of-the-Web with `Unblock-File` does not verify that the file is safe.

### AI-Generated Content

Language-model summaries may contain factual inaccuracies, hallucinations, omissions, or misinterpretations.

Do not treat generated summaries as authoritative substitutes for the original material.

Verify important claims, especially when working with security intelligence, legal documents, medical information, financial information, or other consequential content.

## Known Limitations

- Designed and tested primarily for Windows.
- Long documents may exceed the selected model's effective context window.
- The long-input warning does not automatically split or summarize documents in chunks.
- Model output quality varies by model, document length, and subject matter.
- The tool depends on Fabric's CLI behavior and supported integrations.
- Web and YouTube retrieval require network connectivity.
- Audio/video transcription requires separate configuration and is not guaranteed to remain local.
- Execution timing measures Fabric processing rather than the entire workflow.
- Not all input categories and dependency combinations have been independently validated.
